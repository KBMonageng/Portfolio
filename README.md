# Personal Portfolio | Kabelo Monageng

My personal portfolio website, built to showcase my experience in software quality assurance, my growing automation skills, and my software development projects.

**[View Live Portfolio](https://kbmonageng.github.io/Portfolio/)**

## About the Project

I built this website using HTML, CSS and JavaScript. It brings together my professional experience, technical projects and contact information in one place.

The portfolio is designed to work across desktop and mobile devices, with responsive layouts and accessible navigation.

## Technologies

- HTML5
- CSS3
- JavaScript
- Git and GitHub
- GitHub Pages

## Features

- Responsive layout
- Mobile navigation
- Professional experience section
- Project showcase
- Downloadable CV
- Contact form

## Running Locally

1. Clone this repository.
2. Open the project folder in VS Code.
3. Open `index.html` in your browser or use Live Server.

## Deployment

The website is hosted using GitHub Pages and published from the `main` branch.

**Live website:** https://kbmonageng.github.io/Portfolio/
